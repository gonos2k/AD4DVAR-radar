# 반복 보정의 수학적 계약

현재 계산점에서 g=J_c, H=J_cc를 사용하며 과거 f82 행렬 P는 전처리기로만 사용한다.
각 방향은 현재 H의 PCG 풀이와 별도 실제 잔차 r=Hs+g로 검사한다.
상대 잔차가 eta<=1e-10이면 g^T Hs=-||g||^2+g^T r <= -(1-eta)||g||^2.
이는 Phi의 국소 하강 근거이며 전체 H의 SPD를 증명하지 않는다. J의 하강성 g^T s도 별도로 검사한다.

같은 기준점의 역추적에는 s,Hs를 고정한다. 후보 실제 J/Phi와 엄격한 끝점 분기를 검사하고,
진단·입력/소스/runtime 무결성·시간 검사 이후 c_next를 확정한다. 확정 후 새 현재점의 HVP로 방향을 갱신한다.
비양의 관찰 곡률·선형 거부·dual 후보 소진은 구체적 종료 사유이지 정상점 부재의 증거가 아니다.

최대3반복, HVP90 누적, PCG40/방향, 반경0.05, 최대16dyadic후보, cJ=cPhi=1e-4.
모든 HVP 시작과 완료를 기록한다. 한도 도달 시 이전 확정점을 유지하며 자동fallback/shift/예산증가를 하지 않는다.
전체 방향 norm의 제한은 이차모형 신뢰영역 부분문제의 풀이와 다르다.
정체는 제어 이동이 FP64에서 소실되거나 J/Phi 실제 감소가 수치적 해상도 이하인 경우로 기록한다.

최대 gradient 1e-10 이하 도달은 root_pending_audit이다. 최종 곡률·원래 Hessian 수반·재분석은 별도이다.
J는 동화비용, E는 미래검증점수이므로 J/Phi 감소를 기상예측skill로 환산하지 않는다.
에코대리량은 수분질량이 아니며 유량/속도는 설정된 모델좌표 단위이다.

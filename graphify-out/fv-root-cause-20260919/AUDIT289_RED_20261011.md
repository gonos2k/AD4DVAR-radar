It does not invalidate the successful saved PR289 run, whose started/completed counts are both 2. It does not permit a commit on this failure path: candidate selection and P2 occur only after the loop completes. The guarded parent `.run.json` and resource receipt report child exit/cancellation, so they remain authoritative for an interrupted run; the raw child JSON alone can remain `phase=running`.

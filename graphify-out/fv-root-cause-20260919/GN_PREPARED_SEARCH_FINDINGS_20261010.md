# 준비된 GN 방향의 제한된 실제 검색

PR #278의 확정점 `311f27d0…38ec0652`에서 같은점 연산 근거를 재자격 확인한 뒤, 원래 목적함수와 최소 혼합 정책을 유지하는 별도 24개 반감 격자를 실행했다. 기존 공통 검색의 16개 상한은 변경하지 않았다.

각 후보는 실제 영 유량 차트 이동량, 내부 최소 혼합계수, 원래 J와 잔차 제곱합의 두 Armijo 조건, 후보의 현재 양측 분기와 gradient를 확인한다. 기준점 selector 서명 일치는 진단이며 추가 승인 조건이 아니다. 첫 통과 후보만 독립 P2 재평가와 원자적 저장을 거쳐 확정하며, 다음 계산점에는 새 Jacobian row 24개·12차원 풀이 1회·양측 HVP 2회만 준비한다. 두 번째 후보는 평가하지 않는다.

현재 계획의 계산 횟수는 0에서 시작한다. 이전 계획의 확정 1개와 HVP 2회를 이번 실행 횟수에 합산하지 않는다. 보관된 같은점 HVP 두 벡터의 재사용과 새점의 실제 HVP 두 회를 구분한다.

검증은 영향 시험 14개 통과(1.90초), 오류 수준 타입 검사 0개 오류, 고정 계획 소스 151개·보관 파일 195개 해시 일치와 저장된 이전점 감사다. 합성 시험과 저장 근거는 생산용 미분의 독립 인증을 대신하지 않는다.

실제 실행의 종료 및 수치 결과는 종료 후 저장 감사와 아래 결과표에 기록한다. 적격 최적점·정확 곡률·수반·재분석·독립 미래예측은 완료로 주장하지 않는다. 기존 1차 이론 실증 100%, 현재 FV 확장 가중 마일스톤 70%를 유지한다.

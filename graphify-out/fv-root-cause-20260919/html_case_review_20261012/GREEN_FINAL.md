# GREEN · 표시 근거 검토

독립 GREEN agent는 저장 근거와 HTML/helper를 읽어 10개 사례의 값, 원자료 해시, 링크, 미래점수의 계산점 pairing을 확인했다. 기존 DATA의 scope/metrics/checks/source는 TOY_REPLAY_METRICS와 일치한다. 리뷰 섹션은 marker 내부만 교체하며 기존 replay DATA를 보존한다.

지적된 GN overview의 비교 기준 모호성은 수정했다. PR300의 앞선 9개 큰 후보는 시작점 대비 R 증가, 최종 GN 후보는 시작점 대비 R 감소이나 선택된 gradient 후보보다 R가 높다고 명시한다.

PR304 mapping은 gh read-only 조회에서 현재 draft PR304/branch/head를 확인했다. 새로운 FV·HVP·미래점수 실행 또는 browser 렌더링을 주장하지 않는다. 브라우저 file protocol 거부로 화면 검증은 미수행이다.

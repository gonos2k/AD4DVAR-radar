# 표본 공통 방향의 제한된 원래 비용 탐색

PR #261의 안쪽 두 유한 표본 gradient 선분에서 구한 최소 norm 조합 방향을 마지막 확정점 `2cdccade…`에 실제 적용했다. 기존 원래 J 탐색 kernel을 재사용하는 adapter이며, 목적함수·26개 prior·관측·파라미터·경계·시간과 최종 정상성 기준은 유지한다. 고정 유량 조건이나 새 평활화를 추가하지 않았다.

## 사전 정책과 구현

이번 모드는 **원래 J의 Armijo 비용 탐색이며 Phi는 진단만 한다.** 두 표본의 하강 예측을 현재점에서 다시 확인하고, HVP 한 번으로 방향별 비용 곡률을 계산한다. 유한한 양의 곡률이면 비용 이차모형의 최소 배율을 전체 반경과 1로 제한하고, 유한하지만 비양의 또는 미분해 곡률이면 반경 제한을 사용한다. 비유한 값은 거부한다. 후보는 원래 26변수 affine 경로에 있으며 최대 16회 역추적, 최대 1개 확정점, 내부 240초/외부 300초/표본 RSS 1 GiB를 사전 선언했다.

기존 J Armijo·후보 자체 strict branch·전체 gradient 유한성 조건을 적용한다. 후보가 통과한 뒤에도 J/gradient/Phi 재현과 branch 서명, 소스·입력·runtime·최종 시간 검사를 완료한 뒤 확정한다. Phi의 재현 확인은 감소 조건이 아니다. 실패하면 잠정 후보를 `candidate_not_committed`로 표시한다.

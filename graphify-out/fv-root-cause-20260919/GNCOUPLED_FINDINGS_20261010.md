PR #272 확정점 `c8fba1f93ee0b6c83edc5b56792de158921c0a64bab41eef5403c2a514b1fc33`에서 기존 접선-gradient 방향과 결합 robust-GN 방향을 동일한 후보별 최소 θ 정책으로 비교했다. 실제 F²가 작은 GN 후보를 선택하고 그 한 점만 독립 최종 재평가·확정했다. 이번 계산점·후보 격자·첫 통과 정책에서 GN이 더 유리했다. 일반 수렴·속도 우위를 입증한 결과는 아니다.

## 원래 문제와 계산 범위

원래 J·prior·관측·경계·시간·제어를 유지했다. 현재 26제어·12개의 동일 품질/표준편차 조정 후 whitening 잔차·identity prior·신경 prior 없음·평활화 가중치0·pseudo-Huber δ=2 프로필만 지원한다. 양측 residual 값과 접선 Jacobian row의 일치를 확인하고, robust 비용+prior를 재구성해 native J/양측 J와 대조했다.

P=I−nnᵀ/(nᵀn), t=P g*라 두고 D=diag(ρ″(r)), B=√D A−P, S=I12+BBᵀ를 사용했다. Cholesky로 S의 양의 정부호성을 확인하고 하나의12차원 row-space 풀이로 d=−t+BᵀS⁻¹Bt를 구한 뒤 실제 pivot의 차트로 반올림 수준의 접선 재구성을 했다. 이 GN 검색 근사는 잔차의 비선형 Hessian 항을 생략한다. 최소 θ의 exact mixed multiplier가0이라는 구조와 구분하며, 과거 θ의 곡률 보정을 덧붙이지 않았다. 정확 Hessian·최소점·수반 연산으로 승격하지 않는다.

양의 GN metric은 원래 비용의 접선 하강성을 주지만 최소 혼합 merit 하강을 보장하지 않는다. 각 방향마다 현재 양측 HVP2회를 계산하고, θ′를 포함한 전체 잔차벡터 미분으로 배율을 정했다. optional direction_override는 후보 이동·HVP·θ′·DF·양측 비용 기울기 모두에 같은 GN 방향을 사용한다. 최종 승인에서 개별 양측 gradient·최소 θ·native J·최소 F²·현재 분기·face·입력·소스·runtime·시간을 다시 확인했다.

각 방향의 첫 통과 후보를 비교한다. 전체32개 격자에서 방향별 최적 배율을 찾은 것이 아니다. 비교는 실제 최소 F², 동률 native J, 다시 동률이면 기존 방향 순서(128epsilon 여유)로 사전 고정했다. 미선택 baseline 후보는 독립 최종 재평가하지 않았다. 과거 거부 후보는 새 성공점으로 바꾸지 않는다.

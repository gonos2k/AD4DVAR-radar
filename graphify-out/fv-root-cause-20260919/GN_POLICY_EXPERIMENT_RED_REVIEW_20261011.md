# GN policy experiment — RED preflight review

Read-only source/test review; no FV/HVP or production run. The final preflight source validates the a3d2 P2 parent and uses one shared initial bundle, fresh point-local operators, and the finite-chart successor helper.

- **Canonical promotion:** each endpoint must pass independent P2. `read_bound_endpoint` rehashes every provisional P2 receipt and checks it against policy/J/R metadata; canonical persistence deep-copies the initial state and writes only a recovered endpoint with atomic `_write`. The R-cap endpoint must beat the frozen initial R by the configured margin; a horizon-exhausted path remains provisional. `R_armijo_required` is retained and bounded-policy proposals keep `F_squared_armijo_passed=False` when that test fails.
- **Failure state:** generic child exceptions call `finish(..., failed=True)` and are distinguished from an internal-budget completion. Backend-double tests exercise both outcomes while asserting the canonical prefix stays at the initial control. Atomic canonical-write failure leaves the in-memory canonical prefix untouched. Receipt rehash/tamper and cap tests cover endpoint promotion.
- **Policy/gates:** three arms use original dyadic J/R, seeded J/R, or fixed-initial-R cap. J Armijo, finite/minimum, strict pair/face, side-gradient and native-cost gates remain required for every candidate. The bounded arm omits only R Armijo from eligibility, records its actual boolean, and additionally enforces fixed `R_reference_initial`/`R_cap`; endpoints must recover both J and R before promotion. Search-level tests cover first-pass, expansion/backtrack, zero budgets, R-cap refusals, tie behavior and timeout counters.
- **Limits:** no claim of FV execution, convergence or forecast accuracy is established by this preflight. The optional 1% R cap is the current explicit plan setting, not user confirmation. Arms execute sequentially and share both the initial operator bundle and exact-candidate cache; consequently per-arm elapsed time is order/cache dependent. Compare logical slots, cache hits, fresh backend evaluations and aggregate operator receipts; do not infer standalone speed from arm wall time.

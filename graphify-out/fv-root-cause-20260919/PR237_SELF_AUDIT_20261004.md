수학적 과잉수정 방지: J(c,p)=c²/2, E(c,p)=p이면 c*=0은 p±h에서 동일하고 총응답은1이다. 중앙차분 제어 해시 중복 자체는 오류가 아니다. 제어/파라미터 연결 및 근거 상태를 확인하되, 알려지지 않은 숫자 기준이나 새로운 물리 인증을 만들지 않는다.

숫자·출처 보호: 원래 세 FV 응답, 기존 변환 출력, 과거 검증 manifest는 역사적 자료로 보존한다. 수정으로 code SHA가 바뀌면 새 audit/render 기록을 만든다. 3시간 마지막 정상성 미달·독립 기상 검증 공백은 이번 계약 조사로 종료하지 않는다.

공유 그래프는 기존 a2dde 해시의 데이터와 복구 안내 그대로 유지한다. 변경 코드만 격리 AST 추출하며 전체 CI/FV/GN/수반/재분석을 실행하지 않는다.

# 특정 minmod 사건의 현재 민감도 진단

PR279의 마지막 확정점 `027e83cf…e94c6769`와 그 점의 준비된 접선 GN 방향을 사용한다. 저장된 가까운 거부 후보와 확정 후보의 차이는 양측 모두 trace124의 x방향 choose_left 내부좌표 [1,2] 한 항목이다. 이는 실제 상태 q[2,3]의 좌우 음의 차분 선택이며 면유량 부호 전환이 아니다.

공개 minmod observer는 detach한 복사본을 주므로 자동미분에 사용하지 않는다. 체크포인트 replay의 내부 부수효과 캡처 역시 명시적 출력이 아니어서 안전하지 않다. 별도 계약 복사본에서 replay 저장 전략만 끄고 동일한 이산 analysis_trajectory를 직접 테이프로 실행한다. 원래 problem은 변경하지 않으며 양측 사건 값과 전체 분석 프레임이 원래 replay 경로와 정확히 같은지 확인한다. 이 비교는 수치 연산의 일치를 확인하는 것이며 메모리·실행 경로가 동일하다는 뜻은 아니다.

사건 ζ=L−R의 전체 gradient와 현재 접선 GN 방향의 JVP를 구한다. raw gradient 내적과 면 접선에 투영한 gradient 내적을 모두 대조한다. 정상화된 전체 최소 gap을 사건 거리로 사용하지 않는다. 세 개의 고정된 작은 차트 표본은 사건 실제 값·선형 예측·selector·원래 J·최소 혼합R만 진단한다. 새로운 탐색 제약이나 optimizer 확정은 없다.

첫 실행은 계획 고정 후 팀 helper/test 편집이 발생해 종료 소스 불변성 검사에서 실패했다. 당시 계획·실행·로그·압축 원시 자료를 별도로 보존했다. 그 결과를 성공으로 승격하지 않고 수정 소스와 별도의 두 번째 계획을 고정해 재실행했다. 첫 계획의 helper/test 해시는 남았지만 당시 정확한 소스 바이트의 사본은 보관하지 못했다. 따라서 첫 실패 실행을 해당 소스로 독립 재현할 완전한 패키지라고 주장하지 않는다.

검증: 합성 이벤트 좌표·AD 연결·context 복구·stage 횟수·비유한 입력 및 이전 검색 회귀 12개 통과(18개 기존 경고,1.42초), 타입 오류0. 실제 결과는 아래 종료 근거에서 별도 평가한다. 적격점·수반·재분석·미래예측은 미완료이며 기존1차100%/FV확장70%를 유지한다.

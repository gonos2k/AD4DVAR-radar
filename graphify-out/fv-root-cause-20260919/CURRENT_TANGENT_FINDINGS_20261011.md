# 현재정식점의 접선 방향을 실제 J/R 승인 경로로 연결

PR294의 문제 정의를 기준으로 원래 J의 국소최소화와 선택면 위의 제한된 한 스텝을 구분했다. 현재 P2-closed점 `68a6e821…11f9ed8`의 native J, 개별 양측 gradient, 최소 혼합 vartheta, 27성분 전체 G, 분기·입력·source·runtime을 새로 재자격했다. PR293 진단 교차점의 gradient/법선/방향과 이전점의 GN/row/HVP는 재사용하지 않았다.

현재점의 trace179 x interior[1,2] 사건값과 gradient를 새로 계산했다. public 원래 observer와 직접 테이프의 사건값은 정확히 같고, 양측 외부 연장 간 값도 같았다. L/R 음의 부호, strict 사건 gap과 choose_left/ζ 부호 연결을 현재 trace에 대조했다. 현재 ζ=-1.5483812632e-7이므로 이 점은 ζ=0 교차점이 아니다.

## 방향과 면 가설의 판단

현재 최소 혼합 gradient를 g*, 외부면 법선을 n, 외부면 접선으로 투영한 현재 사건 gradient를 w라 하면 baseline d0=-P_Q g*, event direction dE=d0−w(wᵀd0)/(wᵀw)로 정의했다. 두 방향은 현재 gradient로 생성한 검색 방향이며 GN 방향이 아니다. 잔차 G 자체는 투영하지 않았다. dE는 현재 ζ level의 일차 변화를 제거할 뿐 ζ=0을 강제하지 않는다.

Q의 음/양 바깥 방향의 현재 native 비용 기울기는 각각 +0.19225115/+0.08795874이고 자체 FP64 scale bound보다 충분히 컸다. 따라서 이 한 번의 조건부 탐색은 Q=0 유지로 분류했다. 이 수치가 최소점을 인증하지는 않는다. resolved 음의 outward slope가 나오면 Q0 후보 확정을 하지 않고 `native_face_release_required`로 종료하도록 정의했다. 실제 면 이탈을 수행하는 일반 solver는 아직 아니다.

각 방향에 현재점의 새 HVP 2개를 계산했고, 최소 혼합계수 미분을 포함한 전체 DG[d]로 비용·잔차 하강성을 따로 판정했다. 두 방향 모두 지원됐다. 초기 배율은 새 방향별 모델의 잔차 최소 배율/반경으로 정하며, 과거 GN의 극소 이동량을 새 방향에 고정하지 않았다. 이 실험은 새 방향의 제한된 유효 이동 검사로 사전 계획에 고정한 dyadic J/R 정책이다. seeded GN 비용 개선 실험의 반복이나 속도 비교는 아니다.

새 조건부 연구 endpoint는 `98ee63abf614756ddbdbba5cc480d66a3235a17b4def8c50b084c4f20dcdd957`이다. J 감소0.00141866%, R 감소7.74125141%, norm 감소3.94858221%, 최대성분 감소0.02974327%다. 한 점의 성과이며 모든 성분의 단조 감소·일정 수렴률·원래 문제의 적격 최소점은 인증하지 않는다.

두 arm은 각각 최대24개 격자 중 첫 통과 후보를 반환하고 이번에는 각각 첫 후보에서 통과했다. 전체 격자의 최적 후보 비교가 아니다. 실제 이동량과 모델 배율은 서로 달라 동일 이동 거리의 방향 우열/시간 가속률을 주장하지 않는다. 한 방향만 적격이면 단일 대체 경로로 기록하는 정책을 계획에 명시했지만 이번은 양쪽 후보가 모두 적격해 실제 두 후보를 비교했다.

baseline 후보에서는 trace180 x[1,2] choose_left만 시작점과 달라졌고 trace179는 그대로였다. event 후보는 전체 baseline trace와 같았다. 후보마다 현재 strict pair/face/native 자격과 최종 candidate-vs-repeat trace가 일치했다. selector 불변을 새 승인조건으로 강제하지 않았다.

## 유한 모형과 미래 점수의 구분

baseline의 모델 예측 R은 0.002884323578231425, 실제 R은 0.002884190660581822다. 벡터 오차/실제 변화량은 약0.9530%다. event 방향의 비율은 약0.0008058%로 더 작지만 실제 R은 baseline보다 높았다. 국소 예측의 정확성과 유한 후보의 실제 진전을 분리해 판단했다.

선택과 별도로 native `score()`를 원래 고정 입력에서 no_grad로 계산했다. 두 값은 마지막 관측 이후 +180분, 20셀의 matched-twin dBZ MSE다.

- 시작 E=7.389566482742109 dBZ²
- 선택점 E=7.389658368267996 dBZ²
- 변화 +9.1885525888e-5 dBZ², **0.0012434495% 증가**

E는 후보 선택·Armijo·승격에 사용하지 않았다. 이번에는 J/R 감소와 관찰용 E 개선이 일치하지 않았다. 이를 독립 미래예측·실제 강수 정확도·정확 수반의 인증으로 바꾸지 않는다. 현재점의 forward 미래점수 관찰은 추가됐으나 독립 미래검증과 실제 파라미터 섭동 재최적화는 미완료다.

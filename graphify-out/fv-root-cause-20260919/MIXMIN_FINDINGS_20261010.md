# 후보 혼합계수 최소화의 실제 적용

PR #270의 확정점 `0da57dbc5a4c101c2f24204835a746514b110f4548fe64de40455f4478dfbed1`에서 원래 26제어 문제를 유지한 별도 실행이다. GREEN·RED 팀은 사전 조사에서 실행 상태명 오표기와 영 이동량 후보의 확정 가능성을 발견했다. 실행 전에 모두 수정하고 회귀시험을 추가했다. 영향 시험75개 통과·기존 경고18개(10.11초), 타입 오류0이다.

## 정책과 수학

원래 J·관측·prior·경계·시간을 유지한다. Ψ(c)=minθ ½||[g−+θ(g+−g−),Q/0.84]||²를 사용하며 현재점과 각 후보의 실제 양측 gradient에서 θ를 최소화한다. 해상된 유일 내부해만 지원한다. 경계/해상 불가 후보는 거부·역추적한다. 선형 θ 예측은 진단일 뿐 실제 merit나 후보 도메인 판단에 대신 쓰지 않는다.

벡터 모형에는 θ′=−(jᵀHmix d+gminᵀ(H+−H−)d)/(jᵀj)를 포함한다. envelope의 스칼라 기울기에서 θ′ 항이 상쇄돼도 벡터 미분과 배율에는 필요하다. 실제 J·최소 F² Armijo, 현재 strict 분기쌍·면·곡선 이동 반경을 검사한다. 최종 양측 gradient와 θ 최소값·비용·잔차·분기·입력·소스·runtime·시간을 재평가한 뒤 제어와 θ를 함께 확정한다. 기존 P2 개별 양측 gradient gate를 유지한다.

고정 계획 SHA `9611b13d3392c198f0a92436c1e9536a6286363a2c64a70a48e5b43f6c480576`는 source133개/archive124개를 고정했다. 내부240초/외부300초, 표본RSS1GiB, 반경0.05, 후보16개·확정1개 이하이다. 현재 HVP2회, row reverse/PCG/조밀 풀이/전체 Hessian0회 범위다.

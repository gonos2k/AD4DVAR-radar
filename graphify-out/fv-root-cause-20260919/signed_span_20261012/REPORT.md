# Signed 이동과 실제 미래검증

**Signed 결합은 같은 점에서 실제 J/R를 더 낮췄다. 그러나 현재 후보의 평균·후반 미래오차는 분석장 persistence보다 크다. 정확한 생성 제어가 원래 J의 최소점일 수 없다는 목표 불일치도 확인했다.** 미래검증을 미평가 상태로 남기지 않고 실제 실패 조건을 기록한다.

## 탐색: 비음수 원뿔과 signed span

## 미래: 고정 참값과 독립 시간적분을 실제 실행

선택 후 별도 producer가 세 점의 미래장을 계산했다. 최종 +180분 MSE는 2a4d **7.384565484460**, fb0a **7.384323633729**, 96108 **7.384251516265 dBZ²**다. signed vs fb0a 감소는 **0.000977%**로 작다. score/forward 3회, 최적화/후보/HVP/선택 0회이며 각 18개 미래장을 저장했다. 원시 score-domain 주석(off-grid) 오류는 전체 4×5 검증장으로 정오표에서 바로잡고 raw receipt를 보존했다. [실행/정오표](FORECAST_VALIDATION_FINDINGS.md).

고정 초기·경계와 알려진 생성 제어로 별도 NumPy flux/RHS + DOP853 시간적분을 두 정밀도에서 수행했다. 최대 정밀도 차이 3.57e-7 dBZ, 기존 참값과 최종 차이 1.07e-6 dBZ다. **공간 이산화는 같은 minmod 모형**이며 독립 구현/시간적분 기준이다. 연속 PDE 참값·실자료·보류 기상사례 검증으로 확대하지 않는다.

## 수학적 핵심: 원하는 복원과 현재 J는 양립하지 않음

동일 p의 참 생성 제어에는 identity prior만 **0.9421520472**다. 현재 후보 전체 J는 **0.0609882086**이다. 나머지 손실이 비음수이므로

\[J(c_{true},p)\ge\tfrac12\|c_{true}\|^2=0.9421520472>J(c_{candidate},p).\]

**정확한 생성 제어는 이 고정 J의 최소점일 수 없다.** Solver 속도와 별개의 목표 불일치다. 모든 J 최소점의 예측이 나쁘다는 증명은 아니다. 참 생성 제어의 Q≈0.104도 현재 Q=0 가설 밖이다. 현재 유동 flux 상대 오차 norm은 1.13188, 에코 log 성장/10분은 참값 0.08 대비 0.05493886이다. 알려진 합성 상태 비교이며 실제 관측 풍속·강수 성장의 복원 인증이 아니다. [재현 코드](physical_recovery.py), [결과](PHYSICAL_RECOVERY.json).

같은 점의 방향·회귀 변형을 더 늘리는 일을 우선하지 않는다. 원래 J의 적격 최소점/정확 응답과, 관측·prior·활성면 가설이 기상 목표에 적합한지를 분리한다. 결과를 통과시키려고 목적함수·물리 입력·승인 기준을 사후 변경하지 않았다.

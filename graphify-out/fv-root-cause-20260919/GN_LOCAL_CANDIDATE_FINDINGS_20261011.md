# 진단 후보의 실제 재평가와 한 점 확정

PR #288에서 확보한 국소 미분 근거를 재자격한 뒤, 같은 `454396e7…60be3b7a` 점과 저장 GN 방향에서 두 후보를 새로 평가했다. 과거 진단의 `accepted=False` 기록은 변경하지 않았다. 새 양측 HVP 2회로 재구성한 잔차 방향미분 DG[d]는 보관된 같은 방향의 벡터와 성분별 차이 0이었다. 관측 row와 GN 풀이의 새 실행은 각각 0회다.

| 후보 | 배율 | 실제 R | 기준 selector와 같음 | 판정 |
|---|---:|---:|---|---|
| PR #287 마지막 표본에 해당 | 2.404138610194166e-5 | 0.0031263066786563877 | 아니오 | 선택·최종 재평가·확정 |
| PR #288 첫 표본에 해당 | 1.202069305097083e-5 | 0.0031269538437563244 | 예 | 적격, 미선택 |

두 후보 모두 원래 J/R Armijo, 최소 혼합계수, 양측 분기, 면 조건, 유한성 및 native 비용 정합성을 통과했다. 선택은 실제 R, 동률이면 J, 다시 동률이면 고정 후보 순서로 한다. 기준 selector 불변은 승인 조건이 아니다. 두 후보만 비교했으며 전체 격자 최적 후보를 찾았다고 주장하지 않는다.

새 확정점은 `a3d2ad7bd5b358619c55ca8c52f9ffe15a276a1b0ec10fd4620e440bea30cc5a`다. 원래 J는 0.06102493753540203에서 0.061024895390148964로 약 0.0000690623% 감소했고, R는 0.003127039112866745에서 0.0031263066786563877로 0.0234226111% 감소했다. 잔차 norm은 0.05591338550522931이며 최대 혼합 성분은 0.02658847396545451이다. 원시 부모·새 제어 차이 norm은 9.666049930312492e-7로 후보의 실제 이동량과 일치한다.

선택 후보만 개별 양측 gradient를 포함한 최종 P2 재평가를 통과한 뒤 원자적으로 확정했다. 확정 횟수는 1, 실제 후보는 2다. 새점 GN·HVP·사건 민감도 갱신과 후속 후보는 수행하지 않았다. 작은 하강 확정은 최종 정상점·최소점·수반·재분석의 인증이 아니다.

선택 후보의 벡터 모형 오차 norm은 약 1.46554e-4이며 실제 변화량 대비 약 99.8809%다. 동일-selector 후보는 약 0.00436657%다. 더 큰 실제 감소가 더 정확한 유한 모형을 뜻하지 않는다. 원래 실제 J/R와 최종 gradient 재평가를 계속 채택 근거로 유지해야 한다.

실제 guard 1회는 종료코드 0, 34.205657초, 표본 peak RSS 793,985,024 bytes로 2GiB 범위에서 완료했다. 영향 시험 11개 통과(2.80초), 타입 오류·경고 0개다. GREEN/RED는 저장 근거와 소스·합성시험만 검토했고 별도 FV/HVP를 실행하지 않았다.

남은 제한: 예외 때 후보는 `evaluation_started` 상태와 시작/완료 횟수로 남고, 상위 run/resource로 실패를 판별해야 한다. 후보별 명시적 interrupted 상태 또는 OS 강제 종료 보존의 인증은 아니다. PR #286 수정 3단계 producer의 실제 FV 완주도 이번 실행으로 대신 검증하지 않았다.

기존 이론 실증 100%, 현재 FV 확장 약 70%를 유지한다. 미래점수·정확 수반·재분석·독립 합성 예측 검증은 수행하지 않았다. 다음 연구점은 새 확정점이며, 그 점의 현재 연산을 갱신해야 한다.

# PR239–240 과학 검토 후속 체크리스트

기준 PR240 head9920a232 / main0f533851. 기존 좌표 잔차·norm 안정화 및 새 guarded 경로의 완료 범위는 유지한다.

원본 반례: Z=diag(1e6,1e-8), H의 두 비대각=1e-320에서는 반환 고윳값이 약 ±4.99994e-319(정확한 입력 기준 약 ±9.9999e-319)이다. Z=diag(2,.5), H 비대각=최소 FP64 subnormal에서는 반환값이(0,0)이지만 기준은(-m,+m)이다. 입력 H는 정확히 대칭이고 결과 크기도 표현 가능하며, 중간 풀이의 한쪽 소실이 마지막 평균에 가려진다.

좁은 대응은 normalized B_raw의 상대 비대칭을 평균 전에 검사하는 것이다. 조건수로 허용오차를 크게 늘려 두 반례의 sqrt2 상대 비대칭을 통과시키지 않는다. 이는 발견한 두 경우의 안전한 거부이며 모든 중간 언더플로의 검출 또는 완전한 scaled triangular solver를 주장하지 않는다.

지난3시간 실행의 J/g/분기 재현은 유지하며 새 H/Schur와 완료 HVP 수는 미확보다. 이번에는 실제 FV/GN/HVP/PCG/재분석 또는 장시간 재시도를 시작하지 않는다. 과거 보고서와 source hash를 덮어쓰지 않고 새 기록으로 변경 범위를 구분한다. 원래 정상성 기준·prior·에코/관측 모형은 유지한다. Graphify는 캐시를 참조하고 변경 파일만 격리 갱신한다.


## 완료한 P2 수정의 범위

입력 H의 상대 비대칭과 삼각풀이 직후 B_raw의 상대 비대칭을 분리해 검사한다. B_raw를 대칭화하기 전에 안정적인 norm으로 검사하며, 두 경우 모두 같은 차원 없는64·eps·k 기준을 적용한다. left/B_raw의 비유한 값도 평균 전에 거부한다. 새로운 출력 필드는 입력 근거와 정규화 후·대칭화 전 근거를 구분한다.

원본 helper와 수정본을 독립 실행했고, 원래 두 잘못된 결과와 정확한 입력 Fraction 기준을 재현했다. 수정본은 두 사례를 명시적으로 거부했다. 조건수4 사례도 거부하며, 조건수1e14를 이유로 허용오차를 크게 만들지 않았다. 이는 알려진 소실 경로의 안전한 거부이지 모든 언더플로 검출의 보장은 아니다.

검증: 집중30 passed, 기존 경고18개, 두 파일 오류 수준 basedpyright0. 기존 혼합 대각척도·최소 subnormal 대각·pivot·극소 norm·비대칭 거부 시험을 유지했다. 과거81개 시험과 합산하지 않았다. 실제 FV/GN/HVP/PCG/재분석·장시간 작업은 실행하지 않았다.

재개 가능한 곡률 진단은 RESUMABLE_CURVATURE_DIAGNOSTIC_PROPOSAL_20261004.md에 구현·검증·실행 단계를 명시한 제안이다. 아직 구현 완료 또는 실제 곡률 확보로 집계하지 않는다. 이전 fresh_hessian·64개 원래 수치 소스·실행기록은 불변으로 유지한다.

# 현재 GN 방향과 사건 성분 제거 방향의 제한된 비교

현재 확정점027e에서 원래GN방향과 PR280의 사건gradient에 직교하도록 한 성분을 제거한 Euclidean방향을 비교한다. 양측 사건gradient를 현재 외부면 법선에 다시 투영하고 일치 검사를 통과한 뒤 평균한다. 보정은 탐색 방향만 바꾸며 원래J·관측·prior·경계·minmod와 최종 정상성 기준은 변경하지 않는다.

각 방향의 실제 양측 HVP를 새로 계산하며 같은 방향을 theta미분·잔차미분·차트후보에 사용한다. 각 방향은 자신의 모형 초기배율과 같은 실제반경0.05에서24개반감격자의 첫 통과후보를 찾는다. 두 후보가 있으면 실제최소R, 반올림동률일때J, 다시동률이면원래방향순서로 한점을 선택한다. 선택점만독립P2재평가·원자적저장을 수행하고 멈춘다. 새점row/풀이/HVP준비나 두번째후보는 없다.

비용하강 보관상한은 현재잔차하강·실제유한성공의 증명이 아니다. 사건방향미분0도고차전환을 배제하지 않으며 기준점selector불변을승인조건으로추가하지 않는다. 이동량/후보수차이를 기록하고가속률을사전선언하지 않는다. 소스파일고정후담당편집을중지하고정확한바이트스냅샷을보존한다.

실제결과와독립저장감사·자원종료는완료후추가한다. 기존1차100%/FV확장70%,최적점·수반·재분석·예측성능은미완료로유지한다.

선택의 반올림 동률은 현재R와J각자 규모의128eps를 사용한다. 한 방향이 지원조건을 벗어나면 해당 방향은 미평가/지원거부로 남기고 다른 방향의 통과를 단일지원결과로 구분한다. 양방향이지원될때만 방향비교 완료로 표시한다.

## 실제 비교 및 확정 결과

실행은 118.610초·표본RSS565,428,224bytes·종료코드0에서 완료됐다. 현재점의 새 양측HVP4회, 실제후보총23개(기존22개/보정1개), 독립P2후확정1개다. 두방향 모두지원조건을통과했으며 실제R가작은 사건성분제거 방향이선택됐다. 새점은`48b0f95c5aa485a6a17046d4497a2267a389b1cfb2eeedb75d79e7ba038d5729`이고 theta=0.485844424029다.

선택후J는0.0136622775%, R는2.34910036%, norm은1.18153025% 감소했다. 비용/최소잔차/P2개별gradient/source/input/runtime/deadline이통과한 실제확정이다. 새점의HVP/row/GN준비와후속후보는실행하지 않았다.

보정방향은국소최대제거율을 높인 것이 아니다. 모형효율은86.94%에서2.34%로 낮아졌지만자기모형배율을첫시도에실제로적용해2.3491%감소를얻었다. 대상사건ζ는음수에남았고절대gap은약7.06%줄었다. 일차사건변화0이유한전환을모두배제한증거는아니다. 실제수렴반복·다른점일반화·인과유일성은미검증이다.

보정후전체잔차norm은0.066130324006으로줄었지만최대gradient성분은0.0285818984에서0.0285885679533로소폭증가했다. 모든성분이개선됐다는주장은하지 않는다. 보정모형실제감소/예상감소=1.00226059, 벡터오차/실제변화=0.00337866158다.

단일점의두첫통과후보비교이며방향별최적배율전수탐색이아니다. 이동량·평가비용이다르므로가속률을계산하지않는다. 원래문제의적격최적점·정확곡률·수반·재분석·독립미래점수는미완료다. RSS한도2GiB유지,이번낮은표본peak만으로이전작업과의절감률이나1GiB완주가능성을인증하지 않는다.

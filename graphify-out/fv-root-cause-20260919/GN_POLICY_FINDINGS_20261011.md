# PR291 이후 검색 비용과 R 회복 대조실험

새 반복 실험은 하나의 실행기·검색 정책·FV backend와 고정 계획을 사용한다. 이전 FV·미분·최종 P2 수학을 재사용하고, 부모 fec9 점의 원래 J/G/theta/분기·입력·소스를 재자격했다. 초기 row24/GN/HVP2는 동일점의 세 검색에서 공유했다. 다른 provisional 점 두 개에는 새 연산을 계산했다. 최종 정상성 기준·prior·관측·수송·limiter는 변경하지 않았다.

seed는 `min(alpha_model, 4*previous_actual_movement/||d||)`로 시작한다. 첫 seed가 통과하면 최대 3회 두 배 확대를 시도하며 최초 거부에서 멈춘다. 이번 단조 seed 검색은 첫 후보부터 통과하지 못해 6회 반감 평가로 선택했다. 같은 점·방향·승인 기준에서 22→6, 즉 후보 평가 수 72.7273% 감소를 확인했다. 두 단조 후보는 초기 모델과 cache hit 없이 각각 평가했다. 두 endpoint R 차이는 약 1.12e-14로 매우 작으며 seeded 후보가 수렴에 의미 있게 더 우수하다고 해석하지 않는다.

비단조 정책은 시작 R=0.00312620012952993을 고정하고 R≤0.0031574621308252293을 매 단계 적용했다. 최대 3스텝 내 원래 J와 R를 시작값보다 개선하지 못하면 provisional path로 끝낸다. 각 스텝은 원래 J Armijo·최소 theta·전체 G·물리/분기/면·개별 gradient P2를 유지했다. R Armijo는 첫 두 점에서 false로 그대로 저장했다. 세 번째 점에서는 직전 점 대비 R가 줄었지만 시작 R로는 회복하지 못했다. 그 경로의 J는 약 0.00470% 감소했지만 정식 확정점으로 승격하지 않았다.

따라서 이번 결과는 검색 비용 감소와 제한된 J 기반 정책의 회복 실패를 구분한다. 고정 1%·3스텝·이번 seed/확대 규칙의 결과이며 모든 비단조 방법이 실패한다는 증명은 아니다. 단조 두 arm은 한 점의 검색 비용을 비교하고, 비단조 arm은 최대 3점의 회복 가능성을 탐색했다. 같은 horizon의 종단 수렴률 비교 또는 독립 solver 속도 비교가 아니다.

최종 정식점은 `68a6e8219e79e8367b7fdd049bc25f4c431db9abdda1ba2af7ed0b52411f9ed8`다. J=0.061024868372529385, R=0.0031261974660462934, norm=0.05591240887357916, 최대 성분=0.026588122159547832, 실제 이동량=1.5108556294244685e-8이다. J 감소 0.00000107981%, R 감소 0.0000851988%, norm 감소 0.0000425994%로 극소 진전이다. 최종 자격·수반·재분석·현재점 미래점수는 완료하지 않았다.

## 실제 비용과 기록

ROOT guard 1회는 303.284450초, 표본 peak RSS 809,205,760 bytes(약 0.754GiB), 종료코드0, 자원 종료 없이 완료됐다. row72/GN3/HVP6, 논리 후보45/새 evaluator44/정확한 동일점·방향·배율 cache hit1, provisional P2 5점 및 선정 endpoint 최종 P2 1회, 정식 endpoint 승격1회다. 초기 연산 공유를 새 row/HVP 반복 수행으로 집계하지 않았다.

측정된 pure candidate observation은 147.426초, pure HVP는 46.511초, row/solve 구간은 44.203초였다. row 구간은 legacy hash/write를 포함한다. explicit identity 검사 15.719초, runner write 4.334초, receipt hash 0.116초도 기록했다. P2 repeat 21.514초에는 내부 identity 작업이 포함된다. 이 항목들은 완전히 독립·배타적인 합계가 아니므로 전체 시간을 그 합으로 설명하지 않는다. 후보 observation이 중요한 비용인 것은 확인했지만 이전 620초 실행과의 단순 시간비를 개선률로 쓰지 않는다. 정책 순서·공유 초기 모델·캐시 때문에 arm wall time도 standalone 가속률로 쓰지 않는다.

후보 전체 trace는 한 번씩 별도 receipt에 저장하고 progress에는 작은 근거·해시만 둬 이력 전체를 매번 다시 쓰지 않는다. 각 점은 생성 시점에 P2와 선언한 J/R 정책을 검사한다. 메모리의 회복 endpoint 근거로 승자 arm을 선택하고, 그 arm의 전체 P2 경로 receipt를 재해시·정책 재검사한 뒤 승격한다. 선택점은 다시 계산해 같은 정책 상한을 적용하고 원자 저장 성공 이후 canonical record를 갱신한다. 다른 arm을 포함한 전체 실행 receipt의 해시는 별도 사후 검산에서 확인했다. 회복 실패·일반 예외·시간 종료·지원 거부·예산 소진과 정식 승격을 구분한다.

## 병렬로 준비한 독립 검증

독립 characteristic `exp(st) q0(x-ut,y-vt)`의 셀/면 평균·유입값으로 8/16 격자, lead0.4/0.8의 양성 affine echo-proxy 수송을 확인했다. 마지막 lead 상대 L2는 약 8.14e-4→4.55e-4로 감소했다. 이는 공간/시간 동시 세분화에서 오차 감소 근거이며 균일 차수 또는 현재 레이더 3시간 예측성능 인증은 아니다. echo-proxy 적분을 수분질량으로 해석하지 않는다.

또한 알려진 26제어 curved-face 정상점과 theta를 결합한 27변수 합성 문제의 정확 Fz 전치 수반·직접 응답·해석 재분석을 비교했다. 수반 선형 잔차 약 3.66e-15, 해석 응답 오차 약 3.55e-15, 재분석 중심차분 오차는 h=.002/.001에서 약 7.19e-6/1.80e-6였다. 검색 GN 역행렬을 정확 수반으로 대신하지 않았다. 실제 현재 FV 적격점의 수반 인증은 별도다.

영향 시험24개 통과(6.64초), 타입 오류·경고0, GREEN/RED 사전·사후검토, source182/archive254 핀과 snapshot·실행 bundle/receipt 해시를 검증했다. 과거 frozen 근거는 변경하지 않았다. 기존 이론100%, FV 약70%를 유지한다. 다음 결정은 새 작은 점을 자동 반복하는 것보다 실제 유효 이동과 정책 회복 실패를 좁혀 해석하는 데 있으며, 이 단일 pilot의 결과만으로 solver·최종 허용오차·물리모형을 바꾸지 않는다.

# 원래 문제의 기준후보·자격·종단 검증

이 작업은 `fb0a`와 제어 0의 두 시작점, 고정된 26개 제어·native J·관측·prior를 사용한다. 참고 탐색에는 Q=0와 매 단계 혼합잔차 감소를 강제하지 않는다. 후보 생성과 최소점 자격을 같은 작업에서 처리하며, 미래점수는 후보 선택에 사용하지 않는다.

## A — 원래 문제의 후보와 최소점 자격

- [x] 두 시작점에서 SciPy Powell 참고 계산을 수행하고, 누적 평가와 중단 원인을 보존한다.
- [x] 실제 제어에서 발생한 support 상수 보존 오류를 재현·수정하고 기존 계산점의 비용 동등성을 확인한다.
- [x] 참고후보의 native gradient와 정확한 전체 Hessian을 검사한다. 낮은 비용이나 optimizer 종료를 최소점 인증으로 사용하지 않는다.
- [x] 전체 공간의 Newton 이동에서 실제로 도달한 단일 사건면을 식별하고, 양측 바깥 비용 기울기와 접선 gradient를 검사한다.
- [x] 현재점의 정확한 차트 Hessian으로 국소 보정한다. 계산점을 바꾸면 미분을 갱신한다.
- [x] 누적 예산과 평가 상한을 보존하며 두 유동면의 실제 보정·후속 반복·chord까지 실행한다.
- [x] 최종 후보의 정상성 미달을 기록하고 이전점의 PD Hessian을 최종 자격으로 승계하지 않는다.
- [ ] 적격한 원래 최소점의 정상성·정확 곡률·활성구조를 확보한다. 현재 상태는 지원 미해결이다.

현재 후보 `6ca56498…`의 J는 0.0601191808341518이고 측정한 gradient hull proxy 최대값은 약 0.00114502이다. 최종점의 정확 Hessian/P2는 미수행이다. 이전 `8eff6b1f…`의 음의 곡률과 이후 다른 점의 PD 곡률을 현재점의 자격으로 승계하지 않는다.

## B — 실제 섭동 재최적화와 정확 응답

- [x] 관측 파라미터 0과 배경계수 12의 p±h, p±h/2 실행 인터페이스 및 미인증 기준점 차단을 연결한다.
- [x] 실제 두 유동면의 24D 최적조건과 섭동 재최적화 callback을 연결한다. 물리 실행은 아직 없다.
- [ ] 적격 기준점의 구조에 맞는 정확 최적조건으로 수반을 계산한다.
- [ ] 실제 섭동 후 재최적화, 각 해의 자격·가지 일치, 점수 차분을 비교한다.

기준점의 자격이 확보되지 않았으므로 현재 B는 실행·인증 완료가 아니다.

## C — 상태복원과 미래검증

- [x] 이전 signed 후보의 18개 lead와 persistence를 독립 시간적분 기준에 비교한다. 평균 및 후반 성능 실패도 결과로 보존한다.
- [x] 참제어 prior가 현재 전체 J보다 크므로 참제어가 이 고정 J의 최소점일 수 없음을 확인한다.
- [x] 현재 native 후보의 상태복원 및 18개 미래 lead를 별도로 평가한다. 평균·후반 예측이 persistence보다 나쁘다.
- [x] 기존 HTML 사례표에 A/B/C의 실제 상태와 성공·실패 범위를 반영한다.

독립 시간적분은 동일 공간 이산화의 수치 기준이며, 실제 레이더나 보류된 기상사례 검증을 대신하지 않는다.

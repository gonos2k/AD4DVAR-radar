# 새 확정점의 현재 HVP를 이용한 접선 보정

PR #266의 `6b29dacd…`에서 원래 26개 제어의 목적함수·prior·관측·경계·시간을 유지하고 세 번의 제한된 보정을 완료했다. 매 단계 새 양측 gradient와 분석 360단계의 현재 분기쌍을 확인하고, 각 쪽에서 현재 접선 방향의 HVP를 한 번씩 계산했다. 과거 Hessian이나 방향은 현재 연산으로 승계하지 않았다.

## 방향과 채택 계약

단위 제어법선 ν=n/||n||, gθ=(1−θ)g−+θg+에 대해 d=−[gθ−ν(νᵀgθ)]를 실제 영 유량 차트의 접선으로 복원한다. 두 현재 HVP의 혼합 hθ=(1−θ)H−d+θH+d를 이용해 δθ=−νᵀ(gθ+hθ)/νᵀ(g+−g−)를 구한다. 분모의 해상도, gradient 점프의 법선 정합성, 양측 비용 하강성, F merit 하강성을 각각 확인한다. 이 식은 ambient F=[gθ,Q/.84]의 현재 방향미분 DFv=[hθ+(g+−g−)δθ,nᵀd/.84]이며 projector 미분을 누락한 식이 아니다.

초기 배율은 min(1,.05/||d||,−FᵀDFv/||DFv||²)이다. θ를 잘라 넣지 않고 [0,1] 밖이면 역추적한다. 실제 곡선 제어 이동량을 FV 평가 전에 검사하고, 원래 J와 실제 F²의 두 Armijo 조건 및 후보의 현재 양측 분기를 확인한다. 두 분기는 후보에서 서로 같고 strict여야 하지만 이전점과 같은 limiter 선택을 요구하지 않는다.

확정 전 독립 재평가에서 각 양측 gradient, J/F², trace signature, 제어·θ·면유량·고정입력·소스·runtime·시간을 대조한다. PR #266의 P2 검사를 공통 helper로 재사용한다. 확정점과 그 단계의 후보·재현 근거를 한 번의 원자적 저장에 함께 기록하고, 다음 단계가 거부되면 마지막 확정점과 실제 확정 횟수를 보존한다.
